# CAD 图纸信息脱敏工具

把 DXF / DWG 图纸中的**人名、单位、项目名、电话、证件号、本机路径、文件作者**等敏感信息替换掉，同时保证**几何、尺寸、标高、图层结构、设计说明里的技术内容一个都不动**。

所有处理都在本机完成，不联网、不上传。

---

## 一、快速开始

最省事的是用[桌面版](../desktop/README.md)（到 Releases 页下载安装包）或[网页版](https://drawveil.limch.cc)。下面是直接用 Python 运行主程序的方法：

1. 在终端执行 `python3 cad_desensitize.py gui`（需要 Python 3.8+，只用标准库），浏览器会自动打开工具页面。
2. 把图纸拖进页面，点 **扫描预览**。
3. 在结果表里核对：不想替换的词**取消勾选**，代号可以直接改（比如把“单位02”改成“建设单位”）。
4. 点 **执行脱敏**，下载脱敏后的图纸，以及报告和映射表。

> 想先试一下，执行 `python3 tests/make_samples.py 样例图纸` 生成三张样例图（项目、人员、单位都是虚构的）。

### 处理 DWG

DWG 是封闭格式，需要先安装免费的 **ODA File Converter**：
<https://www.opendesign.com/guestfiles/oda_file_converter>

装好后工具会自动找到它（Mac 默认位置 `/Applications/ODAFileConverter.app`），流程是 DWG → DXF → 脱敏 → DWG。
没装的话，也可以先在 CAD 里把图纸 **另存为 DXF**（选 ASCII，不要选二进制）再处理。

## 二、会改什么、不改什么

| 会替换 / 清除 | 原样保留 |
|---|---|
| 图签、会签栏里的人名（设计、校对、审核、审定、项目负责人……） | 所有图元的坐标、长度、角度、半径、标高 |
| 建设单位、设计单位等单位名称，正文里出现的“××有限公司 / ××设计院 / ××管委会”，以及英文名（“… Design Co.,Ltd.”“… Institute of …”），中英文名用同一个代号 | 尺寸标注及测量值、标注样式 |
| 工程名称、项目名称、工程地址、工程编号、合同号 | 图号（建施-01）、比例、版次 |
| 手机号、座机、传真、邮箱、网址 | 设计说明里的技术内容（C30、HRB400、±0.000、图集号……） |
| 身份证号、统一社会信用代码（都做了校验位验证，基本不会误报） | 图层名、线型、颜色、块结构（只有含敏感词时才替换名称里的那几个字） |
| 银行账号、QQ / 微信号、资质证书号、注册号、执业印章号 | 测量坐标文字（默认保留，可在选项里打开） |
| **文件属性**：作者、最后保存人、标题、关键字、自定义属性、编辑时长、GUID、创建修改时间 | 图签日期（默认保留，可打开） |
| **本机路径**：外部参照、光栅图片、PDF 底图、打印机、打印样式的路径（只留文件名） | 国家标准图集出版单位等白名单里的词 |
| 对象上的超链接 | |
| 文件缩略图、块预览图（缩略图上能看清整张图签） | |
| 签名、印章、出图章、Logo 类图块的内容 | |
| “签名”栏里用线条手写的签名笔迹（样条、多段线、签名图块），表格线不动 | |
| 单位名称左侧用填充 / 多段线画的 Logo | |

**同一个敏感词在所有图纸里都替换成同一个代号**，例如“张伟”在 20 张图里都会变成“人员02”，审图人仍能看出这些图是同一个人做的。

### 它是怎么认出人名、单位的

- **图签“标签→相邻格”**：找到“设计”“审核”“工程名称”“建设单位”等字段名，再取它右边（或下方）那一格的文字。图框是块、名字是属性或普通文字都能识别，图框缩放插入也可以。
- **会签表**：“实名 / 姓名”列下的名字；“孙　昊”这种中间加空格的、每个字单独一个文字对象的，都能识别。
- **属性标签**：图框块属性的标签名，如 `SJ`、`JH`、`SH`、`PROJECTNAME`、`设计人`、`建设单位`。
- **行内写法**：`设计：张三  校对：李四`、`建设单位：××有限公司`。
- **全文模式**：电话、邮箱、证件号等，以及“有限公司 / 设计院 / 管委会”等后缀的单位名称。
- **文件属性里的作者**：图签外如果还出现这个名字，也会一并替换。
- **项目简称**：识别到“杭州明湖花园二期”后，会自动补上去掉城市前缀和“二期”的“明湖花园”，因为布局名、图层名里常用简称。
- **自定义敏感词**：你写的词优先级最高，适合补充识别不到的简称、品牌名、甲方代号。

## 三、处理完怎么确认没问题

每张图处理完都会自动做两项检查，结果写在报告里：

1. **几何指纹比对**：逐个图元比较所有数值类组码（坐标、尺寸、角度、颜色、线宽……），必须**完全一致**。被删除的签名块内容除外，这部分是有意删的。
2. **残留扫描**：重新读一遍输出文件，确认映射表里的原文一个都没剩下。还会扫一遍二进制数据（天正对象、OLE），有残留会提示。

报告文件夹里有：
- `脱敏报告.html`：总览、每张图的校验结果、全部映射
- `映射表.csv / 映射表.json`：原文 ↔ 代号对照
- `改动明细.csv`：每一处改动的位置、原值、新值

> ⚠ **报告和映射表里有脱敏前的原文，只能内部留存，不要随图纸发出去。**

## 四、命令行用法（批量处理）

```bash
# 整个文件夹批量脱敏（含子文件夹），输出到“脱敏输出”
python3 cad_desensitize.py run 图纸文件夹/ -o 脱敏输出/

# 只扫描、出报告，不改文件
python3 cad_desensitize.py scan 图纸文件夹/

# 补充敏感词（可写 原词=替换词；re: 开头为正则表达式）
python3 cad_desensitize.py run 图纸/ -k "明湖=某项目,青禾院=某设计院,re:HC\d{4}-[A-Z]+-\d+"

# 下一批图纸沿用上一批的代号（保证跨批次一致）
python3 cad_desensitize.py run 第二批/ -m "脱敏输出/_脱敏报告(含原文,勿外发)/映射表.json"

# 导出配置文件，按需修改后使用
python3 cad_desensitize.py init-config 我的配置.json
python3 cad_desensitize.py run 图纸/ -c 我的配置.json

# 输出格式：same（默认，与原文件一致）/ dxf / dwg
python3 cad_desensitize.py run 图纸/ -f dxf
```

配置文件说明见 `脱敏配置示例.json`：`keywords` 自定义敏感词、`whitelist` 白名单、`options` 各项开关、`pseudonyms` 代号格式（如把人员改成 `"设计人{n}"`）、`signature_block_pattern` 签名印章块的块名规则。

## 五、需要人工留意的情况

工具只能处理图纸里的“文字”。下面几种情况，敏感信息不是文字形式，需要人工处理：

1. **天正等插件对象**：天正的文字、图名、标注是自定义对象，内部文字存在二进制数据里，改不了。报告会提示“含非标准对象 / 二进制数据中仍检测到”。建议先在天正里执行 **“图纸导出”为 T3 格式**（或分解）再脱敏。
2. **炸开成线条的文字、签名栏以外的手写签名**：“签名”栏下的笔迹、单位名称左侧的 Logo 会自动删除（报告里会列出删了几个图元）；块名含“签名 / 印章 / sign / stamp / logo”的图块会被清空。别处用线条写的字，工具无法识别，请人工删除。
3. **OLE 对象**（嵌入的 Word / Excel / 图片）：默认保留，因为常是门窗表等设计内容。报告会提示数量，确认里面有盖章扫描件的话，可以打开“删除 OLE 嵌入对象”选项。
4. **光栅图片**：图纸里只保存图片路径，图片本身不在图纸里。路径已经清掉，**外发时不要附带公章、签名的图片文件**。
5. **地理位置**：如果报告提示含 GEODATA，在 CAD 里执行 `GEOREMOVE` 删除。
6. **测量坐标**：坐标属于设计信息，默认保留。确实需要隐藏的话，打开“测量坐标文字”选项，坐标文字会被打码，但图形本身的绝对坐标不会平移。

**建议的外发流程**：扫描预览 → 核对映射表 → 执行脱敏 → 用 CAD 打开抽查图签和说明 → 只发 `脱敏输出` 里的图纸。

## 七、网页版

- 在线使用：<https://drawveil.limch.cc>，部署在 Cloudflare Workers 免费版上。自己部署见 [`web/README.md`](../web/README.md)。
- 脱敏引擎就是本工具的 Python 代码，用 Pyodide 在**使用者自己的浏览器里**运行，图纸不会上传到任何服务器。首次打开会下载约 10MB 的运行环境，之后浏览器会缓存。
- 网页版只支持 DXF；DWG 需要先在 CAD 里另存为 DXF，或使用桌面版。
- 源码在 `web/` 文件夹：`src/` 是页面（index.html、app.js、app.css、pyworker.js、worker.js），`web_api.py` 是浏览器接口，`build_web.py` 从主程序生成浏览器用的 engine.py。

## 八、桌面版（Mac / Windows）

安装包在 GitHub 的 Releases 页下载。源码在 `desktop/` 文件夹里，也可以自己在对应系统上双击打包脚本生成：

- macOS：双击 `build_mac.command`，生成 `.dmg`
- Windows：双击 `build_win.bat`，生成 `.exe`

桌面版支持直接处理 DWG（需要安装免费的 ODA File Converter）、同一个人在每批图纸里用同一个代号，以及监视文件夹自动脱敏。
打包方法、首次打开的注意事项、数据存放位置，都写在 [`desktop/README.md`](../desktop/README.md) 里。
